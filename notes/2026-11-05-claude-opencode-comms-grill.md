# Claude <-> opencode communication: Grill / Discovery Notes
Date: 2026-11-05 · Goal: Let opencode agents ask Claude questions when in doubt, and expose a prompt.txt-style file showing exactly what opencode receives from Claude.

## Summary / key decisions
- Ask channel: opencode agent ends its turn with a marked question; plugin wakes Claude; Claude answers via send_message. If Claude does not know the answer, it asks the user, then relays.

- Detection: explicit `QUESTION:` marker required by the brief; parsed in hooks/tracker.ts (pure).

- Brief rule: plugin appends the QUESTION: rule automatically to outgoing prompts (user chose over skill-only). Note: CLAUDE.md says never change MCP behaviour for results; this rewrites inputs, so confirm it is feasible via a hook (flag).

- Prompt file: not a log. It is the composed prompt opencode receives, structured like a system prompt: `{system_prompt}` (what opencode can and cannot do, "generated by u" = Claude) followed by `{prompt for task}` etc. Storage layout still open.

- System part: static, user-editable template file; Claude supplies only the task part. Plugin composes template + QUESTION: rule + task and saves the result.

- Locations: template at `prompts/system.txt` in this repo (versioned, user-edited); composed copy per agent at `<project>/.opencode-monitor/<agentId>/prompt.txt`.

- Follow-ups: appended to the same prompt.txt as dated `## Follow-up` / `## Answer` sections, so it is the full transcript of what opencode received.

- Injection: hook rewrites tool input (agent/send_message) to prepend template + QUESTION: rule, if the mod API allows. prompt.txt is reconstructed from the opencode DB (user message parts), so it is exactly what opencode received. Fallback if API cannot rewrite: skill-driven pasting (flag).

- Pane/wake: new `asking` state shown as "? asking"; wake text carries the question verbatim and tells Claude to answer via send_message, or ask the user if unsure. Reuses once-only wake logic.

- Pane UX: show prompt.txt path per agent only; answers go through Claude (which asks the user in chat if unsure). No in-pane answering.
